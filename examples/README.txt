Welcome to the CSG Qblox Master Folder
**************************************
All important Qblox documents can be found here.


Organization:
- Cluster
	- Experiments
		Contains files for all experiment/prototype pulse sequence to be played by the Qblox Cluster

	- Libraries
		Contains libraries/drivers made in-house for use with various peices of equipment. Drivers for the LeCroy Oscilloscope and the Qblox
		Cluster, and the Sequence Helper library for easier sequencing and I/O connections to the Qblox modules.

	- Testing
		Contains all files pertaining to the testing of the Qblox Cluster. Tutorials made by Qblox and pulled from the QBlox website, as well
		tests made in-house to test various functionalities of the Cluster.

	- Cluster IP
		Text file containing the IP of the Qblox Cluster.

	- Diver and firmware updating
		Text file containing instructions on updating Qblox cluster drivers and firmware.

- Miscellaneous
	All Qblox related files made before the creation of this master folder were dumped here, in the folders they were originally in.
	Important files were migrated to their new locations in the master folder, but if there is a file you are looking for that you 
	cannot find under the Cluster of SPI Rack folders, odds are it was dumped somewhere in Miscellaneous.

- SPI Rack
	- Experiments
		Contains files for all experiments/prototypes to be played by the Qblox SPI Rack.

	- Setup
		Contains a notebook that will set the output range of the D5a modules on the SPI Rack.

	- Testing
		Contains all files pertaining to the resting of the Qblox SPI Rack.

- Outstanding Issues
	Text file containing a list of outstanding issues with any piece of QBlox equipment, as a description of the issue.

- Qblox Information
	PDF with useful information regarding the Qblox Cluster and SPI Rack.
